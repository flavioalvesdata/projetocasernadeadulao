# Guia simples do prospecto

Este site apresenta o programa **Discipulando a Caserna** ao Pr. Glaydston, no contexto do Projeto Caserna de Adulão. As seções 1–7 estão implementadas; as seções 8–15 permanecem como âncoras e dependem de conteúdo e decisões humanas.

## Abrir e navegar

Ao receber uma cópia completa, abra `index.html` no navegador. Use o sumário, o trilho dos cinco movimentos e as abas do escudo. O texto principal continua compreensível sem JavaScript; algumas interações deixam de funcionar.

Os textos e dados de origem ficam em `conteudo/`. Não edite `js/dados/`: esses arquivos são produzidos automaticamente. Para revisar uma alteração, compare a página antes e depois, leia o texto afetado e confirme navegação, teclado e visual móvel.

Ter uma URL pública significa que qualquer pessoa com acesso à internet pode tentar abrir o endereço; isso não equivale a um site protegido. Controle de acesso e indexação exigem decisão institucional. Conteúdo pastoral, seções futuras, aprovações e papéis formais devem ser decididos pelos responsáveis humanos, não por ferramentas automáticas.
